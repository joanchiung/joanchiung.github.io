## 1. hash 是什麼？

hash 是一個函式，丟進去任何資料（一段文字、一筆交易），都會吐出一組「固定長度」的亂碼指紋。例如常見的 SHA-256，不管丟進去的資料多大，輸出永遠是 256 bits（顯示成文字約 64 個字元）。

## 2. hash 最重要的特性：單向、不可逆

hash 只能「正著算」，沒辦法「反著算回去」。就算未來量子電腦成真，也沒辦法把 hash「解密」還原成原始資料，因為 hash 從設計上就是故意讓資訊丟失的（多對一），根本沒有唯一對應的原文可以還原。

## 3. 那 hash 會不會重複？

理論上一定會（鴿籠原理：無限多輸入塞進有限的輸出空間，一定存在重複）。但用現在的電腦去找，要花的時間比宇宙年齡還長，所以實務上可以當作「不會重複」來用。

## 4. 區塊鏈瀏覽器怎麼用 tx hash 查到交易明細？

不是「解密」hash，而是把 hash 當作資料庫的「索引 index」。帳本早就把完整交易資料存好了，用 hash 去查表找出來，不是逆算出來的。

## 5. hash 跟加密 Encryption 差在哪？

用「這筆資料以後需不需要被還原成原本的樣子？」做標準來判斷：

- **需要 → 用加密。** 例如提款金額要給人看、要執行轉帳。加密是資料的「保險箱」，暫時隱藏，但合法的人拿到 key 一定要能打開看到原文。
- **不需要，只要比對是否一致 → 用 hash。** 例如密碼驗證。系統現場重算 hash 去比對，根本不需要知道你的原始密碼。

hash 是資料的「指紋」，用來驗證、當索引，永遠不能也不需要還原。
